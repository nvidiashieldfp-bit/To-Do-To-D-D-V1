
To-Do To-Did PRO — Static Theme v1.0
================================

To-Do To-Did is a silent, focused, and minimal task management application built for power users who value cognitive clarity.

CORE PRINCIPLES
---------------
- Silent: No unnecessary UI noise.
- Local-First: Data exists only on your machine.
- Immediate: Instant interactions, no loading screens.

SUPPORTED LANGUAGES
-------------------
- Portuguese (pt)
- English (en)
- Spanish (es)
- French (fr)

INTELLIGENT SYSTEMS
-------------------
1. Auto Language: Automatically detects your browser language on first load.
2. Auto Theme: Follows system preference (Dark/Light) automatically.
3. Manual Override: Discreet toggle top-right to lock your preferred mode.

DATA & PRIVACY
--------------
- This app uses 'localStorage' for all data persistence.
- Closing the browser or going offline will not affect your data.
- Clearing your browser cache/history for this site will reset the app.
- No data is ever sent to a server.

INSTALLATION
------------
1. Copy the entire 'HTML-THEME' folder.
2. Open 'index.html' in any modern browser (Chrome, Safari, Firefox, Edge).
3. No installation, build steps, or internet required.
