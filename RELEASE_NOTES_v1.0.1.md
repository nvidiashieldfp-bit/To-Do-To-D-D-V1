## 🇬🇧 English Documentation

### Introduction
To-Do To-Did is a task management application designed for speed, silence, and focus. It removes the clutter of traditional productivity tools—no dashboards, no popups, no accounts—leaving only what matters: your tasks.

### Key Features
- **Single Screen Workflow:** Everything happens in one view.
- **Natural Language Input:** Type "Meeting tomorrow at 10am" and press Enter. The app handles the rest.
- **Silent Focus Mode:** Press `F` to enter a distraction-free Pomodoro session.
- **Local-First Privacy:** Your data never leaves your device. Works 100% offline.
- **Smart Sections:** Tasks automatically move between Now, Today, Tomorrow, and Future based on priority and time.

### User Guide
- **Add a Task:** Type in the top bar. Use natural language like "Buy milk Friday evening high priority".
- **Edit:** Click any task text to edit inline.
- **Calendar:** Click 📅 to switch views. Drag tasks to reschedule. Click a day to add a task there.
- **Focus:** Press `F` or click the ⏱️ icon on a task to start a timer.
- **Shortcuts:**
  - `Esc`: Cancel action / Close focus
  - `Cmd/Ctrl + Z`: Undo last completion

## 🇵🇹 Documentação em Português

### Introdução
O To-Do To-Did é uma aplicação de gestão de tarefas desenhada para velocidade, silêncio e foco. Remove o ruído das ferramentas tradicionais—sem painéis, sem popups, sem contas—deixando apenas o que importa: as suas tarefas.

### Funcionalidades Principais
- **Fluxo de Ecrã Único:** Tudo acontece numa única vista.
- **Entrada de Linguagem Natural:** Escreva "Reunião amanhã às 10h" e prima Enter. A app trata do resto.
- **Modo de Foco Silencioso:** Prima `F` para entrar numa sessão Pomodoro livre de distrações.
- **Privacidade Local:** Os seus dados nunca saem do dispositivo. Funciona 100% offline.
- **Secções Inteligentes:** As tarefas movem-se automaticamente entre Agora, Hoje, Amanhã e Futuro com base na prioridade e hora.

### Guia do Utilizador
- **Adicionar Tarefa:** Escreva na barra superior. Use linguagem natural como "Comprar leite sexta à noite urgente".
- **Editar:** Clique no texto de qualquer tarefa para editar na linha.
- **Calendário:** Clique em 📅 para alternar vistas. Arraste tarefas para reagendar. Clique num dia para adicionar.
- **Foco:** Prima `F` ou clique no ícone ⏱️ numa tarefa para iniciar o temporizador.
- **Atalhos:**
  - `Esc`: Cancelar ação / Fechar foco
  - `Cmd/Ctrl + Z`: Desfazer última conclusão
